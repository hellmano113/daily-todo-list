# 每日待办清单

一个轻量的每日待办 Web 应用，支持必完成项 / 选择完成项、每日完成情况与内容记录、日志与知识库沉淀，以及邮件 + 企业微信的定时提醒。

## 功能

- **必完成项 / 选择完成项**：两个分区分别管理；必完成项默认开启提醒，选择完成项可单独开关铃铛。
- **每日记录**：每项可勾选完成、填写当天内容，失焦自动保存；已完成的项可点击 🙈 隐藏，分区标题栏可展开 / 收起隐藏项。
- **日志与知识库**：每日日志按日期归档；内容可收录到知识库，支持标签与搜索。
- **定时提醒**：每天 09:00 与 20:00 检查当天未完成且开启提醒的项目，通过邮件和企业微信群机器人推送；已完成的项目自动跳过。

## 技术栈

- 单文件前端：`index.html`（原生 HTML / CSS / JavaScript）
- 云端数据：WorkBuddy Cloud Service（PostgreSQL，通过 `@tencent-ai/workbuddy-cloud-sdk` CDN 接入）
- 定时任务：WorkBuddy Automations
- 提醒通道：智能体邮箱 + 企业微信群机器人 Webhook

## 使用说明

1. 部署 `index.html` 到任意静态托管服务（需与云服务的 Origin 配置保持一致）。
2. 在页面「提醒设置」中填写接收邮箱、企业微信机器人 Webhook，并打开对应开关。
3. 定时任务按天查询 `todo_items` 与 `daily_logs`，仅对未完成的项发送提醒。

## 数据表

| 表 | 用途 |
| --- | --- |
| `todo_items` | 待办项目（类型、提醒开关、排序） |
| `daily_logs` | 每日完成状态与内容（按 item_id + log_date 唯一） |
| `knowledge_entries` | 知识库条目 |
| `reminder_settings` | 邮件 / 微信通道配置 |

## 隐私

这是一个私有单用户工具，数据靠分享链接的私密性保护，不适合公开分享链接。
